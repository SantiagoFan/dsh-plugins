# 待办事项工作台（Todo workbench）

左侧边栏里的个人待办清单。面板可以直接增删改查，对话里让 Agent 记的待办也会落到同一份清单里。

## 能做什么

- **四种视图 + 日历**：未完成 / 今天 / 本周 / 已完成；「今天」会把逾期的也带上，「本周」按自然周（周一到周日）计算。「日历」按月查看每天到期的待办，点日期查看当天清单，也能直接把某天设为新待办的截止日期。
- **一条待办包含**：内容、分类（工作 / 生活 / 学习 / 其他，也可以自己写）、优先级（高 / 中 / 低）、截止日期、备注、标签。
- **面板操作**：顶部快速添加（回车提交）、搜索、按分类过滤、行内编辑、一键完成 / 恢复、二次确认删除、清理全部已完成；未完成行有独立的绿色「完成」按钮，新增的条目会短暂高亮并滚动到可见位置。
- **对话记录**：跟 Agent 说「记一条待办：周五前把报价单发给王总」，它会调用 `todo_workbench` 工具写进同一份数据；8 秒内面板自动出现这条待办，提示「对话里新增 N 条待办」，并标上「对话」。
- **本机保存**：数据只写本机 `~/.dsh/todo-workbench/todos.json`，不上传。

## 用法

### 面板

1. 点击左侧边栏的「待办事项」图标。
2. 在顶部输入框写一句话，按回车；需要分类、优先级、日期时用旁边的下拉和日期框。
3. 点「备注 / 标签」可以补备注和标签。
4. 鼠标移到某一行可编辑或删除；删除需要点两次「确认删除」。未完成行右侧有绿色「完成」按钮。
5. 「已完成」页签里点「恢复」或左侧圆圈，可以把待办撤回为未完成状态。
6. 切到「日历」页签：左右箭头切换月份，点某一天查看当天待办；点「在这天添加」会把上方快速添加的截止日期设为该天，输入内容回车即可。没有截止日期的待办会列在日历下方的「未安排日期」里，补上日期后就会进入日历。

### 对话

可以直接这样说：

- 「记一条待办：周五前把报价单发给王总，优先级高」
- 「帮我记一下，下周一要给客户回电话」
- 「我今天有哪些待办？」
- 「刚才那条待办做完了」
- 「把‘给客户回电话’恢复到未完成」
- 「把‘给客户回电话’改到周三」

Agent 记录后会简短确认；查询时会读取真实数据，不会编造。

## 数据与隐私

- 路径：`~/.dsh/todo-workbench/todos.json`（目录 0700、文件 0600）。
- 只有标题、备注、分类、标签、日期、优先级等本机数据；不联网、不上传。
- 数据文件损坏时会自动备份为 `todos.json.corrupt-<时间戳>`，然后从空列表继续，面板上会提示。
- 可以用环境变量 `DSH_TODO_WORKBENCH_DIR` 覆盖数据目录（测试用）。

## 已知限制

- 单机单用户使用，没有账号同步、多人协作。
- 不提供系统通知或定时提醒；「今天 / 本周」只是视图过滤，不会主动弹窗。
- 不支持重复任务、子任务、附件。
- 日历只显示带截止日期的待办；没有截止日期的待办仍在「未完成」列表里。
- 同名未完成待办不会重复创建；确实需要两条同名待办时，改一下标题即可。
- 面板接口依赖 `webServer` 服务；该服务不可用时 Agent 工具仍可用，但侧边栏会显示「接口暂时不可用」。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 插件：注册 `todo_workbench` 工具、`/todo-workbench/*` 路由、系统提示与 `todoWorkbench` 服务 |
| `lib/store.js` | 数据读写、校验、日期分组、统计（工具 / 路由 / 测试共用） |
| `client.js` | 侧边栏图标与主面板（React，无外部依赖） |
| `test/store.mjs` | 存储与日期逻辑测试 |
| `test/host.mjs` | 工具与 HTTP 路由测试 |
| `test/client-render.mjs` | 面板渲染冒烟测试（假 React，不需要浏览器） |

运行测试：`node test/store.mjs && node test/host.mjs && node test/client-render.mjs`
